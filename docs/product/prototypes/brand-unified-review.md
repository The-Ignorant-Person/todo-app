# 纸序统一品牌体验：A 方案审阅

2026-10-18，对应 [验证纸序应用官网及配套的统一品牌体验](https://github.com/The-Ignorant-Person/todo-app/issues/8)。

## 已确认

用户先选择体验「一天的任务：查看、添加、完成及离线提示」，浏览三种布局后回复「A」。因此应用方向采用侧栏清单、任务列表与并排详情；不再把 B 或 C 当作同等候选。原始三版仍保留作决定依据。

本次确认只覆盖应用布局方向，不代表官网、帮助、会员页、全部终端及最终视觉规范已经通过审阅。

## 本轮资产

- `brand-day-prototype.html`：原始 A/B/C 对比。
- `brand-unified-prototype.html`：A 方案贯穿官网、应用、帮助及会员入口，使用相邻 CSS 和 JavaScript。
- `brand-unified-base.css`：从第一轮原型提取的基础样式；不是生产设计系统。
- `brand-unified.css`：统一体验的页面布局与窄屏样式。
- `brand-unified.js`：纯内存交互，含合成示例任务、帮助搜索和关键状态演示。
- `../../assets/brand-concept.png`：既有品牌概念板，样式只展示其中标志局部；没有重新设计、生成或提取生产 Logo 文件。

在项目根目录运行 `node tools/brand-prototype-server.mjs`，访问 http://127.0.0.1:4178 。单独审阅使用查询参数 `?scene=home`、`?scene=app`、`?scene=help`、`?scene=membership`。也可直接打开 HTML。

## 设计判断，待用户审阅

官网使用更宽松的纸页构图、衬线标题与品牌文案；高频应用使用清晰的非衬线文字和紧凑的 A 布局。纸白、绿色、墨灰与轻量分隔线贯穿四个界面。网站和应用均保留帮助与会员入口。

帮助提供分类、关键词搜索、无结果状态、可展开的文章与返回应用入口。会员页区分免费用户和高级会员，但具体功能归属、价格、额度、周期及条款保留为待确定，不以样稿代替商业决策；购买入口不可用。

应用支持今天、全部、已完成与清单筛选；添加、完成、重新打开及编辑备注。预览栏可以切换正常、离线、空清单、加载中与加载失败。加载失败与空清单使用不同文案，不把读取失败误报为数据为空。

## 已检查的结果

项目固定 Playwright CLI 与本机 Edge 的实际浏览器检查：

- 从官网进入应用，添加并完成一项任务；模拟离线显示 2 项变更待同步，模拟恢复联网后显示已同步。
- 空清单与加载失败分别显示对应状态；重试可退出失败演示，重置恢复示例数据。
- 帮助搜索「离线」返回 2 篇，能够展开文章。
- 高级会员购买按钮处于 disabled 状态。
- 四个页面在 390px 视口下，文档宽度均为 390px。
- 已视觉检查官网、帮助、会员桌面截图，以及官网和应用窄屏截图。浏览器中无页面错误报告。

以上仅验证原型。不是实际账号、持久化、离线存储、同步、支付、产品验收或全平台验证。没有执行完整无障碍审计，也未批准生产字体或设计 token。

## 仍需用户反馈

官网、帮助和会员页与 A 应用是否协调；关键提示是否清楚，以及需要调整的具体位置。获得反馈后再确认本票结论，归档最终版本并更新地图；本票当前保持开放。
