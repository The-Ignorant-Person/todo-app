# 纸序范围收尾提案

2026-10-17。**Q17–Q20 待用户确认**，不是既定决定或实现报告。所属决策：[冻结纸序全端软件官网与配套的验收范围](https://github.com/The-Ignorant-Person/todo-app/issues/5)。Q1–Q16 不重问。补充事实来自官方公开页面；未登录外部服务、获取用户数据、购买或实机测试。

## Q17 日历方向

推荐采用下列明确边界，关联与撤销入口、同步后显示在各主客户端提供；字段、重复事件与删除冲突由领域票制定。

| 来源 | 推荐首发动作 | 证据与边界 |
| --- | --- | --- |
| Google | 外部事件查看、新增／修改／删除并回写；另提供选定纸序清单与 Google 日历的任务—事件双向关联 | [官方说明](https://help.dida365.com/articles/6950000554735042560)明确两种模式，不能用“订阅”一词推定只读；不承诺所有特殊事件类型都能转换 |
| iCloud | 查看、创建外部事件并回写；修改／删除也作为纸序目标纳入 | [官方说明](https://help.dida365.com/articles/7190959639616290816)明确添加会同步；本文未找到编辑／删除的直接参照证据，后两者是纸序建议目标，须核实接口权限 |
| Outlook、Exchange、企业微信、钉钉、飞书、通用 CalDAV | 查看并刷新外部事件；有写权限的日历支持新增／修改／删除，明确只读日历不能写 | [Outlook](https://help.dida365.com/articles/7190959706343473152)、[Exchange](https://help.dida365.com/articles/7193074856341012480)、[企业日历](https://help.dida365.com/articles/7190959806838996992)说明关联／查看，未逐项证明写回。保留可写事件是纸序自身目标；需要逐服务补证，不宣称协议名就保证第三方可写。不新增这些来源的任务—事件双向转换 |
| URL、节假日日历 | 只读订阅／刷新，不提供外部事件写回 | [URL 官方说明](https://help.dida365.com/articles/7190979764138541056)为订阅查看；只读是明确产品边界 |
| 纸序向其他日历输出 | 用户选择清单生成可撤销订阅链接；接收方只读 | [参照出口](https://help.dida365.com/articles/6950000444106080256)已明确，不能只做输入而漏掉输出；权限、令牌轮换及内容范围交领域／安全票 |

验收：每种模式分别进行合成事件创建、源端更新、纸序更新（可写项）、删除、拒绝写入、撤销；双向关联另测任务与事件对应及重复同步。当前全部未执行。

## Q18 小组件和穿戴动作

推荐小组件按功能模块冻结，不复制参照每种尺寸和皮肤数量。手机／平板分开验收，旧系统仍执行已定客户端下限。

| 端 | 推荐模块与动作 |
| --- | --- |
| iPhone／iPad、Android | 任务、日历、四象限、习惯、专注、纪念日；显示数据、进入对应模块。任务快速创建／完成、习惯打卡、启动专注，在宿主支持直接交互时直接执行，否则打开主应用完成 |
| 原生 HarmonyOS | 任务、日历、四象限、习惯、纪念日卡片；同类查看与操作，启动专注通过主应用入口；锁屏查看／快速添加按系统能力门槛提供 |
| macOS | 任务、日历、四象限、习惯、纪念日组件，专注从主应用／菜单入口操作；通知中心与系统允许的桌面展示分别测 |
| Windows／Linux | 任务、日历、四象限、习惯、专注、纪念日桌面小窗；查看、任务完成、习惯打卡与专注启动。Linux 是纸序目标，不是参照已验证事实；不用桌面环境原生插件作为唯一交付形式 |
| Web | 应用内模块及浏览器快捷入口，不额外承诺操作系统小组件 |

证据：[小组件官方说明](https://help.dida365.com/articles/6950366960659988480)按端列出上述模块差异；iPhone 锁屏需 iOS 16、iPad 锁屏需 iPadOS 17、iOS 交互及 StandBy 需 17、控制中心需 18、Mac 桌面交互需 14、Watch 叠放需 10。推荐保留这些支持端专属入口及模块动作；控制中心含添加／今日任务、番茄／正计时、日历／四象限／专注／习惯入口。门槛只描述对应功能，不提高客户端安装下限。鸿蒙具体锁屏门槛及厂商卡片宿主仍待补证；只在经核实的宿主出现可用入口。

穿戴维持 Q16 的基本交互及 Apple Watch 专注／组件；**推荐首发不承诺完整任务详情编辑、附件／协作管理和脱离手机的独立云账号客户端**。断连后可以查看最近同步缓存并明确更新时间；新建、完成、打卡若不能送达则不显示成功，提示连接手机重试。本轮不要求离线排队写入。联网可用时的基本动作不因这一边界被删去；断连、恢复、失败不假报是必验项。

## Q19 迁移和课表输入

推荐每个来源提供下列真实路径，Web 执行预览、确认与结果报告；不依赖用户手工重抄全部任务，不向来源写入或启动持续同步。实际字段映射、源版本和有效样本由领域票在最终规格前锁定。

| 来源 | 推荐支持的输入路径 | 一手依据 |
| --- | --- | --- |
| 滴答备份 | 用户主动导出的备份 CSV；先核验格式与可迁字段 | 既有合成 Web 观察只证明 CSV 入口，未取得完整样本；纸序不读取滴答私有云接口 |
| Todoist | 官方项目 CSV，支持用户解压备份后的多个项目文件 | [官方 CSV 说明](https://www.todoist.com/help/account-and-billing/security/import-or-export-a-project-as-a-csv-file-in-todoist-YC8YvN)；导出没有的内容不能虚构 |
| Microsoft To Do | 用户显式授权后的单次只读提取，完成后断开 | [Microsoft Graph](https://learn.microsoft.com/en-us/graph/api/todotasklist-list-tasks?view=graph-rest-1.0)支持 Tasks.Read；文档明确世纪互联中国云不支持该接口。推荐以全球服务的个人及组织账号为目标，组织策略拒绝时如实报错，不宣称支持中国云此路径 |
| Things 3 | 官方导出的数据库副本中 main.sqlite；附打包文件解包指引，不接触运行中的原库 | [Things 官方导出](https://culturedcode.com/things/support/articles/2982272/)；数据库 schema 需锁定样本，不把 SQLite 文件存在当字段已解析 |
| OmniFocus | 官方 CSV／CSV UTF-16 导出 | [OmniFocus 4 手册](https://support.omnigroup.com/documentation/omnifocus/universal/4.7.1/en/database/)；不要求读取其完整专有备份格式 |
| Toodledo | 官方任务 XML、任务／笔记 CSV | [官方工具页](https://www.toodledo.com/tools/import_export.php)；层级、完成历史等覆盖依据样本列明 |
| iCal | .ics 事件文件导入；与持续 URL 订阅分开 | [Apple 导出说明](https://support.apple.com/guide/calendar/import-or-export-calendars-icl1023/mac)；不承诺读取所有 .icbu 私有归档或任意非标准文件 |

每条路径至少有正常、空数据、中文／时区、重复导入、损坏文件或授权拒绝用例；导入报告区分成功、未支持字段与失败，禁止静默丢弃。第三方附件链接不能冒充附件内容已保存。纸序自己的备份与恢复另行覆盖已定义用户数据，不能因源应用导出有限就缩小纸序备份。

课表推荐保留三条路径：**手工建课、单张图片识别后校对、支持名单内的教务网导入**；独立课表视图、在日历／智能清单显示、课程修改和提醒一起纳入。图片以 JPG／PNG 清晰课表为输入目标，不承诺任意 PDF／Excel 或任意版式自动识别；用户明确触发，识别不直接落库。

[滴答课表说明](https://help.dida365.com/articles/6950372717036044288)明确图片预览校对及教务网两种入口，并说明学校适配会受教务系统变化影响。推荐不照抄“近千所”的数量：在独立补证票列出可取得证据的首发学校／教务系统名单，逐条交用户确认。没有名单与成功路径不能把“教务网导入”标记交付完成。复杂课表管理保留 Q16 的 Web 集中管理许可；各主端可看结果、课程详情及提醒。

## Q20 冻结含义与后续责任

推荐将 Q1–Q20 作为**范围目标基线**。这不等于冻结实现技术、确认第三方准入或通过产品验收。若接受本轮，范围票可在登记下列补证责任后记录结论；新增功能另行提出变更，评估影响并由用户决定，不能随参照更新无限扩大首发。

1. 新建有界补证票，锁定候选穿戴的具体型号／固件／手机配对、组件宿主门槛、各服务写权限与账号类型、导入版本／样本、教务网首发学校名单；现有已选目标保留。调查给出建议，无法支持的组合必须回到人工范围决定，不能自动从目标中剔除。该票阻塞最终规格审定，必要时也阻塞依赖它的技术选型；它不是把未知写成已确认适用。
2. 已有领域票负责数据语义、迁移字段、重复规则和冲突；架构／原型负责实现路线；主体／渠道负责资格与发布；商业票负责权益；质量票负责具体运行配置、阈值及设备证据。需要新产品取舍时单独提出，不能借后续票篡改本基线。
3. 基线允许的替代只有已列 Web 管理跳转、组件直接交互不可用时进入主应用、明确只读日历及穿戴断连行为。必需主端能力、写回目标或设备组合不可行时携证据返回，不能统称“系统不支持”后取消。第三方撤销访问应停止请求并如实提示，不虚报同步成功。
4. 最终规格审定必须包含已确认的完整支持名单、版本窗口实例、逐端用例和证据状态；没有闭合不得进入实施交接。以后产品交付仍需正式发布、注册、支付和真实端验收，规划关票绝不等于交付完成。

本轮事实资料支持输入路径与功能区别；尚无来源样本解析、授权、商店资格或真机结果。继续查证不会替代用户对上述目标和明确排除项的选择。
