# 纸序日常任务体验：REA 对标与设计取舍

> 已被用户否定的历史版本。当前工作区已依据滴答参考重做，见 [重做记录](paperdo-workspace-rebuild-20261018.md)。下文检查与选定结论只描述旧版。

日期：2026-10-18。服务于 [验证纸序应用官网及配套的统一品牌体验](https://github.com/The-Ignorant-Person/todo-app/issues/8)。不是完整竞品审计，也不是产品实现验收。

## 结论与授权

用户撤回了原 A 布局的优先地位，并明确委托代理对标滴答、使用 REA、独立决定设计。重新比较后，选定「任务优先的自适应工作台」：桌面默认导航与任务两栏，选中任务才展开详情；900px 及以下使用单列任务与模态详情抽屉。官网、帮助、会员入口沿用纸白、墨绿、墨灰和既有品牌标志。

这是代理的设计判断：在本轮「一天的任务」路径上，渐进展示和可恢复操作比始终展开详情、纯纸页长滚动或固定时间分栏更合适。我选择这一方向来争取超越参照的使用体验。没有相同任务、相同设备的竞品计时试验或真人研究，不能据此声称已证明全面优于滴答。

## 观察与取舍

| 维度 | 证据事实 | 纸序决定及理由 |
| --- | --- | --- |
| 信息结构 | [滴答功能页](https://dida365.com/features?language=zh_CN)公开描述清单、任务、详情三栏，以及其他视图 | 保留可识别的导航与任务关系，但详情按需出现。减少未选任务时的空面板；不据此断言滴答不能收起详情 |
| 快速输入 | 功能页及帮助搜索中的添加任务文章说明列表顶部输入、回车保存及快捷操作 | 常驻输入栏，Enter 保存，N 聚焦。先写下来再展开详情，不借设计决定扩展自然语言解析范围 |
| 帮助入口 | [帮助中心](https://help.dida365.com/)首屏突出搜索、分类和功能指南；输入「添加任务」实际显示约 21 条结果及高亮 | 帮助标题直接说明用途，搜索常见任务用语，分类与结果同时可见，文章可在原处展开。当前仅六篇示例，未做到参照的内容广度或检索能力 |
| 可恢复操作 | 本次没有测量滴答撤销、备注草稿和真实离线恢复的完整行为 | 纸序原型明确提供撤销、关闭后保留草稿、离线变更数量。它们是本产品的要求，不把参照未知当作其缺点 |
| 品牌与场景 | 纸序既定品牌为纸张、自然、平静；滴答公开页采用自身品牌系统 | 官网使用更宽松纸页与衬线标题；任务界面使用系统无衬线、弱装饰和持续可见的操作。对齐成熟产品的可用性，不复制其商标和装饰 |
| 会员 | 本票未验证滴答购买流程；纸序商业决策尚未完成 | 只定入口、免费/高级方案区分、说明和帮助的结构；不填造价格或权益，不建立支付 |

## 原三方案重新比较

- **A 常驻侧栏与并排详情**：清单定位直接，适合桌面；原实现未选择任务也保留详情位，窄屏详情落在长列表下方。保留导航思想，取消原布局的固定地位。
- **B 一日一页**：适合短清单的专注阅读；纸页装饰与上下详情增加纵向距离，频繁切换清单不够直接。纸感留给官网与品牌表达，不选作默认任务工作台。
- **C 时间与待办分栏**：有利于比较具体时刻；没有时刻的日常任务被分到另一栏，小屏需要重新排列。作为未来时间视图的参考，不作为所有任务的默认入口。
- **选定的自适应工作台**：统一任务列表；桌面渐进展开详情，窄屏模态编辑，完成可撤销。它与 A 共享熟悉的导航结构，但并非延续用户先前选 A 的约束。

## 验证与边界

原型在固定 Playwright 1.64.1 / 本机 Edge 上完成 29 项断言，结果见 [检查记录](evidence/paperdo-design-checks-20261018.json)。四个场景与移动详情的 axe WCAG A/AA 自动规则未发现违规；桌面、移动截图已人工查看。自动扫描不等于完整无障碍认证。

检查中修复了页面状态属性意外匹配导航处理器、拦截备注表单提交的问题。另一个最初失败的断言假定原生 dialog 的 Shift+Tab 不能进入浏览器界面；检查证实焦点可暂时离开网页，但不能进入后方页面控件。改以背景控件不可聚焦和 Escape 恢复焦点验证，未用手写焦点圈替换原生行为。

本次没有证明真实离线持久化、跨设备同步、账号、支付、长清单性能、触摸真机、屏幕阅读器、所有终端或总体任务效率。它们分别由质量验收、商业、支持名单和最终规格票承接。本票仅决定品牌体验与交互方向，不缩减已经接受的产品范围。
