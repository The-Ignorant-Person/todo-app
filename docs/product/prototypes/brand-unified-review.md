# 纸序统一品牌体验：选定自适应工作台

2026-10-18，对应 [验证纸序应用官网及配套的统一品牌体验](https://github.com/The-Ignorant-Person/todo-app/issues/8)。

## 当前决定

用户要求设计对标并争取超越滴答，由代理自行判断；随后明确要求使用 REA，并重新选择原 A/B/C 布局。旧的 A 选择已撤回为约束，保留为历史。无须再等待逐页审美确认。

经 REA 公开页观察、原型对比和实际浏览器检查，选定「任务优先的自适应工作台」。详见 [对标证据与取舍](../../research/paperdo-design-benchmark-20261018.md)。此处是结论的原型入口，最终 resolution 以 GitHub 子票为准。

## 设计契约

- 桌面默认导航与任务两栏；选任务才出现第三栏。900px 及以下为单列任务，详情以原生模态抽屉出现，关闭后回到原任务焦点。任务区不沿用原 B 纸页构图或 C 固定时间分栏。
- 添加栏持续可见；Enter 保存、N 聚焦、/ 搜索、Esc 关闭详情。完成后可撤销；备注草稿在本页面关闭/重开详情时保留。输入框内快捷字母不抢输入。
- 任务包含日期与具体时刻的不同展示。未填写时刻不显示零点。支持今天、全部、已完成、三个示例清单及当前视图搜索/排序。
- 离线状态显示可继续编辑及待同步数量；空清单、加载与读取失败分别呈现。失败文案不暗示任务被删除。所有联网状态都是演示。
- 纸白 `#faf7f0`、面板 `#fffdf8`、墨绿 `#365d46`、墨灰 `#303c34`、次级文字 `#61695e` 贯穿页面。任务正文用系统无衬线；衬线主要用于品牌及网站大标题。核心动作目标至少 44px，键盘焦点可见。
- 官网强调品牌与进入应用的主路径；帮助提供搜索、分类、展开说明与返回应用。会员页展示方案关系与帮助入口，价格、权益、周期、条款仍待商业决定。

## 运行与资产

在项目根目录执行 `node tools/brand-prototype-server.mjs`，打开 http://127.0.0.1:4178 。场景参数为 `?scene=home|app|help|membership`；可直接打开 HTML。

- `brand-unified-prototype.html`：当前四场景入口。
- `brand-unified-base.css`、`brand-unified.css`：历史基础样式及当前场景/自适应样式。
- `brand-unified.js`：合成任务、网站、帮助、会员和演示状态。
- `brand-workspace.js`：选定工作台的交互层，供本次比较使用；不是生产代码架构。
- `brand-day-prototype.html`：历史三版，仍可比较，不再待选。
- `../../assets/brand-concept.png`：用户既有品牌板，CSS 展示局部；未提取生产 Logo。

## 验证结果

29 项浏览器断言通过，覆盖添加/撤销/备注保存与草稿/搜索/离线计数/键盘/移动详情焦点/关键状态/页面跳转；四场景 390px 以及详情在 320、768、900、901、1024、1280px 无水平溢出。五个场景的 axe WCAG A/AA 自动规则没有违规，检查中没有页面 JavaScript 错误。详见 [可公开检查记录](../../research/evidence/paperdo-design-checks-20261018.json)。

官网、应用、帮助、会员桌面图与窄屏应用/详情已视觉查看。REA 还单独复放本原型的离线添加、完成与撤销，结果记录在证据索引。

以上仅支持原型决策。数据在内存中，刷新重置；没有真实账号、持久化、同步或支付。会员价格/权益仍待定；完整无障碍、真机、多端性能与生产品牌资产由后续质量和最终规格工作承接。
