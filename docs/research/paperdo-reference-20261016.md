## 结论与证据口径

全端纸序目标保留：Web、Windows、macOS、Linux、iPhone/iPad、Android、HarmonyOS、浏览器插件、小组件、参照产品穿戴配套，以及官网、帮助、订阅与集成。本报告提供调查拆分依据，不把资料少的平台删除，也不要求各端功能完全一致。

- **本轮官方资料**：本日从 dida365.com 与 help.dida365.com 获取的公开页面。部分帮助页直接打开无正文，改从同一官方 URL 的搜索索引读取；索引抓取时间从当天至数日前，可能落后于实际页面。它们是官方声明，均非本轮产品实测。
- **既有 Web 实测**：工作区 `docs/research/dida-web-observations.md` 及其证据索引记录的 2026-10-15 至 16 合成数据观察。本报告只复核文字记录，没有重新运行这些操作。未上传其原始快照、账号内容或私人诊断文件。
- **未知**：缺当前端版本、账号权益或设备测试；不以未知推定不支持。
- 已读取本地 `docs/product/reference-scope.md`、`baseline-draft.md`、`discovery.md`。这些文档当前不在此研究分支，因此只作为既有项目记录引用，不制造失效的相对链接。

优先修正的认识是：官方协作专文已描述只读、可评论和可编辑角色，旧调查不能再写成“完全未发现只读角色”；但真实权限执行仍未验证。FAQ 内同时存在旧、新描述，需保留矛盾，不能选一段就冻结行为。

## 必须保留的冲突与会员缺口

1. **附件限额矛盾仍存在，而且在 FAQ 同页出现**：旧段99/天，新段199/天；会员页199/天。更强的新描述不构成实测。不能原样照抄为纸序限额。[FAQ](https://help.dida365.com/articles/6950670128287580160)、[会员](https://dida365.com/upgrade?language=zh_CN)
2. **角色资料已更新，但文字未完全统一**：FAQ 一处有三种角色，另一处仍称加入者都能编辑；协作专文能佐证角色存在。实际角色对指派、附件、导出等动作的权限未知。[FAQ](https://help.dida365.com/articles/6950670128287580160)、[协作](https://help.dida365.com/articles/6950652002518958080)
3. **免费/高级数字不能消除行为未知**：套餐列免费/高级清单9/299、单清单任务笔记99/999、提醒2/5、习惯及纪念日5/299；“共享成员2/29”的计数是否含所有者仍须澄清。文本抽取不能可靠还原所有图标对比项，尤其 AI 权益不要从空白单元格推断。[会员](https://dida365.com/upgrade?language=zh_CN)
4. **日历数量与真实交互分开**：既有 Web 记录有7个入口、设置文案称6种；本轮公开功能页也只列部分视图名称。当前没有真实会员日历操作证据。[功能页](https://dida365.com/features?language=zh_CN)
5. **旧更新不能当作当前平台差异**：2025更新曾写某日历批量功能 Windows/Web 已上线、Mac 开发中，只能证明当时公告，不能推定2026年仍如此。[2025 更新](https://help.dida365.com/external/articles/7505894191243722752)
