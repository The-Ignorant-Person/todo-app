# 一天的任务：品牌体验原型

2026-10-18。对应「验证纸序应用官网及配套的统一品牌体验」：https://github.com/The-Ignorant-Person/todo-app/issues/8 。已认领，尚未解决。

用户选择首先体验「一天的任务：查看、添加、完成及离线提示」。本轮不重做既定品牌、范围与领域契约。

## 运行

在项目根目录执行 `node tools/brand-prototype-server.mjs`，访问 http://127.0.0.1:4178 。仅监听本机回环地址。也可直接打开相邻 HTML 文件。

## 比较的问题

- A 侧栏清单：任务与详情并排，侧栏提供入口。
- B 一日一页：单列纸页，详情在任务列表下方。
- C 时间与待办：定时任务按时刻排列，未指定时刻的任务单独列出。

底部箭头与键盘左右方向键切换，URL 为 `?variant=A|B|C`。三版共享同一批示例任务与页面内操作状态。原型不持久化；刷新会重置。离线、变更计数及联网同步均为模拟，没有真实账号或网络同步。原品牌概念板通过页面样式局部展示，未提取或重绘生产 Logo。

## 本轮检查

使用项目固定的 Playwright CLI 和本机 Edge：

- 在模拟离线状态添加任务，页面显示「1 项变更待同步」。
- 完成新任务后显示「2 项变更待同步」。
- 切换到 B 后仍显示待同步 2，待办数量为 5。
- 恢复模拟联网后显示「已同步」。
- 三版在 390px 视口下 documentElement.scrollWidth 均为 390px。
- 查看桌面 A/B/C 和窄屏 B 截图；截图位于 output/playwright/brand-day-*，仅为原型布局检查。

以上不证明真实离线存储、同步、跨端支持或完整无障碍验收。官网、帮助、订阅入口与其他关键状态尚未制作。未验证的价格、权益和设备能力未加入原型。
